# WhaleWhistleProject
final year project dealing with the implementation of a device called whale whistle. The code in this document is mainly in 2 files. the main.c, in which most of the code for the Micro controller was written, partly based on stm32cube IDE.
The other main file is angle_est.m, which is a matlab code in which the angle estimation was done as part of the preperations towards the deadline of the project, that was in order to show initial results.
